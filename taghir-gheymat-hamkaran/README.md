# تغییر قیمت همکاران

افزونه ووکامرس برای پر کردن قیمت **همکار نقد** و **همکار شرایط** از روی قیمت اصلی محصول.

**سازنده:** این پلاگین را من، رضا غلامی، ساختم.

## این افزونه چه می‌کند؟

در پنل محصول دو فیلد قیمت همکار وجود دارد که معمولاً خالی می‌مانند:

| فیلد | معنی |
| --- | --- |
| `_knd_colleague_cash_price_above` | قیمت همکار نقد |
| `_knd_colleague_installment_price_above` | قیمت همکار شرایط |

این افزونه همه محصولات (ساده و متغیر) را می‌خواند، درصد را از **قیمت اصلی قبل از تخفیف مشتری** کم می‌کند و همان دو فیلد را پر می‌کند.

مثال: قیمت اصلی ۱٬۰۰۰٬۰۰۰ تومان، قیمت فروش با تخفیف ۸۰۰٬۰۰۰ تومان، درصد نقد ۴۰ و شرایط ۳۰:

- همکار نقد: ۶۰۰٬۰۰۰ (از روی ۱٬۰۰۰٬۰۰۰ نه ۸۰۰٬۰۰۰)
- همکار شرایط: ۷۰۰٬۰۰۰

درصد نقد و شرایط را می‌توانید دستی عوض کنید. پیش‌فرض ۴۰٪ نقد و ۳۰٪ شرایط است.

## چرا ذخیره ۵۰تایی؟

همه محصولات در **یک صفحه** دیده می‌شوند (صفحه‌بندی ووکامرس ندارد). خواندن و ذخیره اما مثل ویرایش گروهی ووکامرس **۵۰تا ۵۰تا** انجام می‌شود.

اگر وسط کار نت قطع شود، کار از اول شروع نمی‌شود. با دکمه **ادامه ذخیره** از همان دسته ذخیره‌نشده ادامه می‌دهد.

## نصب

1. پوشه `taghir-gheymat-hamkaran` را داخل `wp-content/plugins` بگذارید.
2. از پیشخوان وردپرس افزونه **تغییر قیمت همکاران** را فعال کنید.
3. ووکامرس باید نصب و فعال باشد.
4. اگر قبلاً قطعه کد `colleague-price.php` را در Code Snippets فعال کرده‌اید، آن را خاموش کنید تا درصد دو بار اعمال نشود.

## مسیر استفاده

**ووکامرس → تغییر قیمت همکاران**

1. درصد همکار نقد و همکار شرایط را وارد کنید. ستون قیمت جدید همان لحظه عوض می‌شود.
2. روی **خواندن همه محصولات** بزنید. محصولات ۵۰تا ۵۰تا می‌آیند ولی همه در همین صفحه می‌مانند.
3. موارد لازم را تیک بزنید (پیش‌فرض همه انتخاب‌اند).
4. **شروع ذخیره ۵۰تایی** را بزنید.
5. اگر اتصال قطع شد، صفحه را دوباره باز کنید و **ادامه ذخیره** را بزنید.
